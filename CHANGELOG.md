# Changelog

All notable changes to Smart Markdown Copy extension will be documented in this file.

## [2.0] - 2026-06-19

###  Enhanced Features
- **Perfect Style Preservation**: Now captures ALL formatting including dark code blocks, proper list indentation, and heading styles
- **Enhanced Popup UI**: Beautiful new design with gradient background and better user experience
- **Clipboard Detection**: Automatically detects text in clipboard when popup opens
- **Visual Feedback**: "Copy is Ready!" toast notification with success animation
- **Improved Code Block Styling**: Dark theme code blocks with syntax highlighting colors
- **Nested List Support**: Proper indentation for multi-level lists
- **Blockquote Styling**: Left border with gray background matching my style
- **Better Link Handling**: Blue underlined links preserved

###  Bug Fixes
- Fixed issue where code blocks weren't preserving formatting
- Fixed list indentation in Microsoft Word
- Improved clipboard reading permissions

###  Performance
- Faster text processing
- Optimized CSS injection
- Better memory management
